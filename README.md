# Hardware Keyboard: Companion — source archive

Hardware Keyboard: Companion (HWC) has been retired and removed from App Store sale. This repository preserves an archival snapshot of its iOS companion app and keyboard extension source from version 3.0 (build 191).

This is **source code only**. It does not include the Xcode project, build or release tooling, signing configuration, app assets, Core ML models, lexicons, private documentation, website, or original repository history. It cannot be built as-is. There are no binaries or ongoing release commitments here.
